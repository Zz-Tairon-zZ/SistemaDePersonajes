# SistemaDePersonajes
Sistema de Juego RPG en Java Implementación orientada a objetos de un juego de rol que utiliza herencia, polimorfismo e interfaces. El sistema incluye una clase base abstracta Personaje, clases intermedias PersonajeFisico y PersonajeMagico, y clases concretas como Guerrero, Mago, Arquero, Hechicero y Asesino.
